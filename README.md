# Оно тебе надо

Одностраничный сайт аукциона вещей, в которые никто не верил. Проектная работа первого спринта курса Яндекс Практикума "Фронтенд-разработка".

## Запуск

Откройте `index.html` в браузере. Все изображения и шрифты лежат в проекте и подключены относительными путями.

## Состав проекта

- `index.html` — семантическая разметка страницы;
- `fonts/` — локальные шрифты Raleway и их подключение;
- `images/` — оригинальные изображения обложки, карточек, логотипов и соцсетей;
- `styles/global.css` — исходные глобальные настройки;
- `styles/style.css` — оформление разделов и повторно используемых элементов;
- `.github/workflows/tests.yml` — исходный файл автоматической проверки.
